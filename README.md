# Ejercicios de pilas

Ejercicios de omegaUp resueltos en Java, usando una pila propia
(clase PilaArreglo, que implementa la interfaz IPila).

**Autora:** Yaneli Sánchez Cárdenas · Grupo GTID244
Universidad Tecnológica del Norte de Guanajuato (UTNG)

## Ejercicios

- 5308. ()[]{}<>
- 4086. Conjunto
- 6818. Los Últimos Serán Los Primeros
- 1019. Operaciones con una pila
- 3878. Paréntesis Regulares
- 8672. Sumando con pilas

## Contenido

- Carpeta `src`: código en Java (IPila, Nodo, PilaArreglo y un archivo por ejercicio).
- Archivo PDF: explicación de cada ejercicio con capturas de la terminal y de omegaUp (100% en todos).

## Cómo ejecutar (terminal)

    javac src\*.java
    java src.P5308
